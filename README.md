## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev) (v3.19+ recommended)
- Android Studio / Xcode
- Dart 3.x

### Running the Consumer App
```bash
cd consumer_app
flutter pub get
flutter run
```

### Running the Astrologer App
```bash
cd astrologer_app
flutter pub get
flutter run
```
